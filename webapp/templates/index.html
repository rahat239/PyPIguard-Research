    03 KNOW THE LIMITS OF THIS INSPECTION

    This tool analyzes real, live package code using a machine learning model trained on real, archived malicious PyPI packages and real benign packages. Independently validated at 0.983 ROC-AUC on unseen data. It is a triage aid, not a guarantee — some sophisticated or disguised malicious code can still pass undetected (measured evasion rate: 9% under simple code transforms). Always review unfamiliar packages yourself before installing in a sensitive environment.

    PyPIGuard is a static-analysis research tool. Model trained on the ASE 2023 pypi_malregistry dataset and PyPI's official package index.
